# Recipe Analysis

A data analysis project focused on exploring and understanding recipe datasets.

## Goal
The long-term goal of this project is to build an application or website 
that helps users find meal ideas based on the ingredients they have at home.

## Current Progress (Week 1)
- Loaded and explored a dataset of 13,493 recipes
- Cleaned missing values and unnecessary columns
- Analyzed the most common ingredients
- Filtered recipes by ingredient and cooking method

## Current Progress (Week 2)
- Built ingredient matching algorithm
- Added partial matching with missing ingredient detection
- Added recipe title search
- Converted results to JSON format
- Organized code into reusable functions

## Planned Features
- Ingredient-based recipe search
- Meal suggestions based on available ingredients
- Recipe filtering by cooking method and time

## Tools Used
- Python
- Pandas
- Matplotlib
